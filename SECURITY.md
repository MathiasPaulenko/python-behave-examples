# Security Policy

## Scope

This is an educational examples repository, not a production service. Still,
if you find something that could expose users to risk — e.g. a vulnerable
dependency pinned in `requirements.txt` or unsafe patterns that others might
copy — please report it.

## Supported Versions

Only the `main` branch is maintained.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open a public issue for security reports.

Instead, report privately through one of these channels:

- [GitHub private vulnerability reporting](https://github.com/MathiasPaulenko/python-behave-examples/security/advisories/new)
- Email: mathias.paulenko@gmail.com

Include a description of the issue, steps to reproduce, and any relevant
files or versions. You can expect an acknowledgement within a few days.
