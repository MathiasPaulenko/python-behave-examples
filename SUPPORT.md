# Support

## Documentation

- [README](README.md) — quick start, usage, configuration and known issues
- Each demonstrated library has its own docs — see the ecosystem tables in
  the README for links.

## Getting help

- **Bug reports** — open an issue using the
  [bug report template](../../issues/new?template=bug_report.md).
- **Feature requests** — open an issue using the
  [feature request template](../../issues/new?template=feature_request.md).
- **Questions** — use
  [GitHub Discussions](../../discussions) or open a plain issue.

## Security issues

Do **not** open a public issue for security vulnerabilities — follow the
process described in [SECURITY.md](SECURITY.md).
